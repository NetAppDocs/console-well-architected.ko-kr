= Workload Factory에서 Flex Unified 리소스를 검색합니다.
:allow-uri-read: 




[[discover-flex-unified-resources-in-workload-factory]]
=== Workload Factory에서 Flex Unified 리소스를 검색합니다.

Workload Factory는 이제 ONTAP API 프록시 엔드포인트를 통해 Google Cloud NetApp Volumes Flex Unified 기본 모드 및 ONTAP 모드 스토리지 풀과 볼륨을 찾을 수 있습니다. 이러한 리소스는 인벤토리에 표시되며, 아키텍처 최적화 평가 및 권장 사항에 포함됩니다.

link:https://docs.netapp.com/us-en/console-well-architected/gcnv/configuration-analysis-gcnv.html["Google Cloud NetApp Volumes의 구성 분석에 대해 알아보기"]



[[enter-flex-unified-systems-from-netapp-console-canvas]]
=== NetApp Console Canvas에서 Flex Unified 시스템 입력

이제 NetApp Console 캔버스에서 검색된 Google Cloud NetApp Volumes Flex Unified 시스템에 대해 *시스템 입력*을 선택할 수 있습니다. 그러면 선택한 시스템의 리소스 페이지가 열리고 기본 모드 시스템에서 사용 가능한 것과 동일한 워크플로를 사용하여 연결된 스토리지 풀 및 볼륨을 볼 수 있습니다.

link:https://docs.netapp.com/us-en/console-well-architected/gcnv/configuration-analysis-gcnv.html["Google Cloud NetApp Volumes의 구성 분석에 대해 알아보기"]



[[well-architected-assessments-for-flex-unified-resources]]
=== Flex Unified 리소스에 대한 잘 설계된 평가

잘 설계된 대시보드는 이제 Google Cloud NetApp Volumes Flex Unified 스토리지 풀 및 볼륨의 SSD 용량 여유 공간, 볼륨 용량 여유 공간 및 스냅샷 정책 적용 범위를 평가합니다. 결과는 Google Cloud NetApp Volumes 잘 설계된 환경에 표시되며 기본 모드 또는 ONTAP 모드의 리소스를 식별합니다.

link:https://docs.netapp.com/us-en/console-well-architected/gcnv/configuration-analysis-gcnv.html["Google Cloud NetApp Volumes의 구성 분석에 대해 알아보기"]



[[well-architected-issues-displayed-in-netapp-console-systems-page]]
=== NetApp Console 시스템 페이지에 표시되는 잘 설계된 아키텍처 문제점

Google Cloud NetApp Volumes의 아키텍처 관련 문제에 대한 알림은 NetApp 콘솔의 스토리지 관리 시스템 페이지에서 확인할 수 있습니다. 이 기능을 통해 Google Cloud NetApp Volumes 시스템의 구성 문제를 신속하게 파악하고 알림에서 워크로드 아키텍처 대시보드로 이동할 수 있습니다.
