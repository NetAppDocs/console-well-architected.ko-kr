NetApp Console의 well-architected 대시보드의 새로운 기능을 알아보십시오.



[[30-august-2026]]
== 2026년 8월 30일



[[remote-data-replication-assessment-for-cloud-volumes-ontap]]
=== Cloud Volumes ONTAP의 원격 데이터 복제 평가

Cloud Volumes ONTAP 데이터가 원격 복제로 보호되는지 확인할 수 있는 새로운 평가를 사용할 수 있습니다. 이를 통해 데이터 보호 계획이 재해 복구 및 비즈니스 연속성에 대한 모범 사례를 따르도록 보장할 수 있습니다.

link:https://docs.netapp.com/us-en/console-well-architected/cvo/configuration-analysis-cvo.html["Cloud Volumes ONTAP의 구성 분석에 대해 알아봅니다"]



[[dismiss-entire-well-architected-configurations]]
=== 잘 설계된 구성 전체 무시

이제 대시보드에서 권장 구성 전체를 해제할 수 있습니다. 이를 통해 사용자의 환경에 표시되는 권장 사항 및 평가를 더욱 세밀하게 제어할 수 있습니다.



[[database-workload-recommendations-in-the-well-architected-dashboard]]
=== 잘 설계된 대시보드의 데이터베이스 워크로드 권장 사항

FSx for ONTAP을 사용하는 데이터베이스 워크로드에 대한 권장 사항이 이제 NetApp Console의 잘 설계된 대시보드에서 제공됩니다. 스토리지 리소스와 데이터베이스 워크로드의 상태를 한 곳에서 확인할 수 있으므로 인프라 상태를 완벽하게 파악할 수 있습니다.



[[17-august-2026]]
== 2026년 8월 17일



[[fsx-for-ontap-support-in-the-well-architected-dashboard-in-netapp-console]]
=== NetApp Console의 well-architected 대시보드에서 FSx for ONTAP 지원

NetApp Console의 well-architected 대시보드는 Amazon FSx for NetApp ONTAP에서 사용할 수 있습니다.

link:https://docs.netapp.com/us-en/console-well-architected/fsx/configuration-analysis-fsx.html["FSx for ONTAP의 구성 분석에 대해 알아보기"]

NetApp Console의 잘 설계된 대시보드에 이제 새로운 스토리지 구성 이름이 포함되었습니다.

다음 표는 기존 구성 이름과 잘 설계된 대시보드의 해당 새 구성 이름을 나열합니다.

| 파일 용량 임계값 | 파일 용량 여유 공간 


| 장기 보존 데이터의 신뢰성 | 복제 정책 레이블 


| 예약된 로컬 스냅샷 | 스냅샷 정책 


| 불필요한 백업 삭제 | 백업 만료 


| 불필요한 스냅샷 삭제 | 스냅샷 만료 


| SSD 용량 활용률 저하 | SSD 용량 과잉 프로비저닝 


| 비활성 블록 장치 | 비활성 블록 장치(LUN)

[[well-architected-issues-displayed-in-netapp-console-systems-page]]
=== NetApp Console 시스템 페이지에 표시되는 잘 설계된 아키텍처 문제점

Cloud Volumes ONTAP에 대한 아키텍처 문제 알림은 NetApp Console의 스토리지 관리 시스템 페이지에서 Microsoft Azure의 Cloud Volumes ONTAP에 대해 제공됩니다. 이 기능을 통해 Azure의 Cloud Volumes ONTAP 시스템에서 구성 문제를 신속하게 파악하고 알림에서 워크로드 아키텍처 대시보드로 이동할 수 있습니다.



[[10-august-2026]]
== 2026년 8월 10일



[[google-cloud-netapp-volumes-support-in-the-well-architected-dashboard]]
=== Google Cloud NetApp Volumes 지원(잘 설계된 대시보드)

NetApp Console 대시보드에서 이제 Google Cloud NetApp Volumes를 지원합니다. 스토리지 관리자는 스토리지 풀 및 구성 상태를 확인하고, 효율성, 비용, 성능, 안정성 및 보안을 개선하기 위한 권장 사항을 받아보고, 운영을 최적화하고 모범 사례를 따르기 위한 조치를 취할 수 있습니다.

link:https://docs.netapp.com/us-en/console-well-architected/gcnv/configuration-analysis-gcnv.html["Google Cloud NetApp Volumes에 대한 구성 분석"]에 대해 자세히 알아보십시오.



[[03-august-2026]]
== 2026년 8월 3일



[[fix-dismiss-and-reactivate-configurations-for-cloud-volumes-ontap-in-microsoft-azure]]
=== Microsoft Azure의 Cloud Volumes ONTAP 구성 수정, 해제 및 재활성화

NetApp Console의 잘 설계된 대시보드를 통해 이제 Cloud Volumes ONTAP 시스템에 대한 구성 권장 사항을 수정할 수 있습니다.

또한, 아키텍처 분석에서 하나 이상의 구성을 제외할 수 있습니다. 이를 통해 사용자 환경에 적용되지 않는 특정 구성을 무시할 수 있습니다.

나중에 해제된 구성을 포함하려면 잘 설계된 대시보드에서 다시 활성화할 수 있습니다. 이렇게 하면 구성이 분석에 복원되어 권장 사항 및 수정 사항을 확인할 수 있습니다.

link:https://docs.netapp.com/us-en/console-well-architected/cvo/\improve-configurations-cvo.html["Microsoft Azure의 Cloud Volumes ONTAP 구성 수정, 해제 및 재활성화"]

== 2026년 7월 20일



[[introducing-the-well-architected-dashboard-in-netapp-console]]
=== NetApp Console의 잘 설계된 대시보드 소개

NetApp Console의 아키텍처 최적화 대시보드는 계정 및 지역 전반에 걸쳐 스토리지 시스템과 구성을 한눈에 볼 수 있도록 지원합니다. 이 대시보드는 운영 효율성을 극대화하는 데 도움이 되는 인사이트와 권장 사항을 제공합니다. 구성의 아키텍처 최적화 상태, 사용 중인 스토리지 유형에 대한 아키텍처 최적화 프레임워크의 핵심 요소별로 정리된 구성 문제, 그리고 구성 문제 및 권장 사항 목록을 확인할 수 있습니다.

link:https://docs.netapp.com/us-en/console-well-architected/learn-well-architected-dashboard.html["잘 설계된 대시보드"]에 대해 자세히 알아보십시오.

Console의 잘 설계된 대시보드는 link:https://docs.netapp.com/us-en/console-well-architected/cvo/configuration-analysis-cvo.html["Microsoft Azure의 Cloud Volumes ONTAP."]에서 이용할 수 있습니다.

https://docs.netapp.com/us-en/console-well-architected/learn-custom-rules.html["사용자 지정 규칙에 대해 자세히 알아보기"]
